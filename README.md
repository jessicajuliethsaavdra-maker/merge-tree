# Merge Tree

Merge Tree es un juego sencillo de estrategia y mezcla de elementos, donde el objetivo es combinar fichas o recursos iguales para crear versiones más poderosas y alcanzar la mayor puntuación posible.

Este proyecto está pensado como un juego casual, fácil de entender y divertido de jugar, ideal para practicar lógica, diseño de interfaz y mecánicas de juego.

## Descripción del juego

En Merge Tree, el jugador debe gestionar un tablero con elementos que pueden fusionarse. Cuando dos elementos idénticos se combinan, pasan a formar una nueva pieza con mayor valor. A medida que avanza el juego, la dificultad aumenta y el espacio disponible se vuelve más limitado.

El objetivo principal es:
- combinar elementos iguales;
- crear piezas más fuertes;
- evitar saturar el tablero;
- alcanzar la mejor puntuación.

## Funcionalidades

- Tablero interactivo
- Mecánica de fusión simple
- Sistema de puntuación
- Reinicio del juego

- Posibilidad de ampliar con animaciones, sonidos y niveles

## Cómo jugar

1. Inicia el juego.
2. Selecciona un elemento disponible.
3. Combina dos piezas iguales para crear una nueva.
4. Continúa fusionando para sumar puntos.
5. Si el tablero se llena, el juego termina.
6. Intenta superar tu mejor puntuación.

## Controles

- Mouse: hacer clic para seleccionar y mover piezas
- Teclado: usar flechas o WASD si se incluye movimiento del tablero
- Enter o Espacio: confirmar acciones o reiniciar la partida
